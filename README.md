# Сервер лобби Hogs of War

Сервер для сетевой игры в Hogs of War через интернет. Он хранит список комнат и пересылает сообщения игры между игроками одной комнаты. Саму игру он не знает и ничего в ней не считает.

Игра подключается к нему с [исправлением Hogs of War](https://github.com/accidev/hogs-of-war-fix): адрес сервера пишется в его `hogs.ini`.

## Запуск

Нужны Docker с Compose и открытый TCP-порт 47800.

Готовый архив: [hogs-of-war-server.zip](https://github.com/accidev/hogs-of-war-server/releases/latest/download/hogs-of-war-server.zip). Он собирается сам при каждом изменении сервера. Распакуйте его на сервере и в его папке выполните:

```
docker compose up -d --build
```

Или через git:

```
git clone https://github.com/accidev/hogs-of-war-server.git
cd hogs-of-war-server
docker compose up -d --build
```

Проверка:

```
docker compose ps
docker compose exec lobby python check.py
```

Первая команда должна показать состояние `healthy`, вторая — имя сервера и список комнат (пока пустой).

Порт 47800 должен быть открыт в файрволе сервера и у хостинга. Проверка снаружи, с любого компьютера с Python и копией этого репозитория:

```
python check.py адрес.сервера
```

## Подключение игроков

В `hogs.ini` игры, раздел `[Network]`:

```
Server=адрес.сервера
```

Если порт не 47800: `Server=адрес.сервера:порт`. У всех игроков одной комнаты должна быть одна версия исправления.

## Настройки

Настройки задаются в файле `.env` рядом с `compose.yaml`. Файла может не быть: тогда действуют значения по умолчанию.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `HOGS_PORT` | `47800` | порт на сервере |
| `HOGS_NAME` | `Hogs of War lobby` | имя сервера, латиницей |
| `HOGS_MAX_CLIENTS` | `200` | сколько подключений сервер держит сразу |
| `HOGS_MAX_PER_IP` | `16` | сколько подключений с одного адреса; `0` — без ограничения |
| `HOGS_FRONT_SECRET` | пусто | секрет для работы только через Cloudflare Worker, см. ниже; до 63 байт |

После правки `.env`: `docker compose up -d`.

## Обновление

Из архива: скачайте новый, распакуйте поверх старой папки (файл `.env` останется) и выполните `docker compose up -d --build`. Через git:

```
git pull
docker compose up -d --build
```

Перезапуск обрывает идущие игры: комнаты живут только в памяти сервера. Перед остановкой сервер говорит каждому подключённому, что он перезапускается, и через секунду закрывает соединения.

## Журнал

```
docker compose logs -f
```

В журнале видно, кто открыл комнату, кто вошёл и вышел. На каждое отключение одна строка: адрес, номер игрока, причина (молчал дольше положенного, закрыл сам, обрыв соединения, сервер закрыл за нарушение, перезапуск), сколько секунд был подключён, сколько кадров прислал, самая долгая задержка из-за ограничения скорости, сколько секунд назад пришёл последний кадр и сколько байт принято и отправлено. По последним трём числам видно соединение, которое оборвалось в пути: кадры перестали приходить задолго до отключения. Если кадры ждут дольше секунды, об этом тоже есть строка, не чаще раза в 10 секунд на подключение. Там есть IP-адреса игроков. Журнал ограничен тремя файлами по 10 МБ.

Если у всех игроков в журнале один и тот же адрес вида `172.x.x.x`, Docker подменяет адреса. Тогда ограничение `HOGS_MAX_PER_IP` считает всех игроков одним: поставьте `HOGS_MAX_PER_IP=0`.

## Cloudflare перед сервером

Чтобы игроки не видели адрес сервера, перед ним ставится Cloudflare Worker из `cloudflare/worker.js`. Игра подключается к адресу Worker по WebSocket, Worker открывает TCP-соединение с сервером и передаёт байты в обе стороны. Сам сервер при этом не меняется.

1. В панели Cloudflare: **Workers & Pages**, создать Worker, вставить в него `cloudflare/worker.js`.
2. В настройках Worker добавить секрет `ORIGIN` — адрес сервера в виде `адрес:порт`, например `203.0.113.5:47800`.
3. Включить адрес `workers.dev` у этого Worker.
4. В `hogs.ini` игры: `Server=wss://<имя Worker>.<поддомен аккаунта>.workers.dev`.

Если открыть адрес Worker в браузере, он покажет список игр: сколько игроков онлайн и какие комнаты открыты (название, хозяин, игроки, идёт ли бой); игры с паролем только считаются. Страница обновляется сама каждые 5 секунд на русском или английском, по языку браузера. Тот же список в виде JSON лежит по адресу `/rooms.json`. Worker сам спрашивает сервер и держит ответ 5 секунд в кэше Cloudflare.

### Только через Worker (по желанию)

Без этого порт сервера открыт всем, и к нему можно подключиться напрямую, минуя Worker. С секретом сервер принимает только подключения, пришедшие через Worker:

1. Придумайте секрет, до 63 байт, например `openssl rand -hex 24`.
2. На сервере в `.env`: `HOGS_FRONT_SECRET=<секрет>`, затем `docker compose up -d`.
3. В настройках Worker добавьте секрет `FRONT_SECRET` с тем же значением.

Значение должно быть одним и тем же и там и там, и задавать его нужно в обоих местах или ни в одном. Пока секрет задан, адрес сервера для игры напрямую (`Server=адрес:47800`) перестаёт работать, и `python check.py адрес.сервера` с другого компьютера тоже: сервер закрывает такое подключение без ответа и пишет в журнал причину. Подключения с самой машины сервера (`check.py` внутри контейнера) секрета не требуют и в ограничениях не считаются.

Worker передаёт серверу настоящий адрес игрока (`CF-Connecting-IP`): `HOGS_MAX_PER_IP` и журнал считают игроков по нему, а не все вместе по адресу Cloudflare.

Что нужно знать:

- **Нужен платный тариф Workers.** На бесплатном Cloudflare обрывает соединение через одну-две минуты боя: у одного соединения там около двух секунд процессорного времени. На платном в настройках Worker ставится предел процессорного времени 300 000 мс; его хватает на несколько часов игры одного игрока.
- **Все игроки приходят с адресов Cloudflare.** Без секрета (см. выше) ограничение `HOGS_MAX_PER_IP` считает их вместе: поставьте в `.env` значение `HOGS_MAX_PER_IP=0`.
- **Переезд сервера.** Достаточно поменять секрет `ORIGIN`. Адрес у игроков остаётся прежним.
- Задержка между игроками через Cloudflare — около 125 мс, на 30 мс больше прямого пути (замер 14.11.2026, два клиента на одном ПК).
- Без `HOGS_FRONT_SECRET` порт сервера по-прежнему открыт в интернет. Адрес сервера знает только тот, кто видит секрет Worker.

## Что сервер делает для защиты

- Учётных записей и паролей нет: подключиться может любой, кто знает адрес.
- Подключение, которое за 10 секунд не представилось, закрывается. Молчащее 90 секунд — тоже. Игрок в комнате, который сообщил, как часто шлёт PING, закрывается быстрее: после `max(10, 3 × период)` секунд тишины.
- Кадр длиннее 16384 байт или не по протоколу закрывает подключение.
- Кадры одного подключения читаются не быстрее 100 в секунду (300 подряд — сразу), запрос списка комнат считается за 20 кадров. Лишние ждут в соединении: игру это не обрывает, а засыпать сервер не даёт. Если кадр пришлось бы ждать дольше 5 секунд, сервер сообщает об этом и закрывает подключение.
- Не больше 100 комнат и 8 игроков в комнате.
- Контейнер работает без прав root, с файловой системой только для чтения и пределом памяти 256 МБ.

Содержимое сообщений игры сервер не проверяет: это должен делать клиент.

## Файлы

| Файл | Что в нём |
|---|---|
| `hogs_server.py` | сервер, один файл, без зависимостей (проверен на Python 3.13 и 3.14) |
| `check.py` | запрос имени сервера и списка комнат; им же контейнер проверяет себя |
| `test_server.py` | тесты: `python -m unittest -v test_server` |
| `PROTOCOL.md` | протокол между игрой и сервером |
| `Dockerfile`, `compose.yaml` | образ и запуск |
| `cloudflare/worker.js` | Cloudflare Worker перед сервером: скрывает его адрес и показывает список игр |
| `.github/workflows/package.yml` | при каждом изменении в `main` прогоняет тесты и собирает архив для релиза `latest` |

Без Docker сервер запускается так: `python hogs_server.py`.
